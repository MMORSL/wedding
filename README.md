# Свадебное приглашение — Гульбарият и Николай

Одностраничный сайт-приглашение на свадьбу (15 ноября 2026, Санкт-Петербург).

## Файлы
- `index.html` — сам сайт. Все изображения и оформление встроены прямо в файл.
- `wedding-music.mp3` — фоновая музыка. Запускается при открытии конверта; выключается кнопкой ♪ внизу справа.

> Важно: оба файла должны лежать рядом (в одной папке). Музыка подключается относительной ссылкой `wedding-music.mp3`.

## Публикация на GitHub Pages
1. Создайте **публичный** репозиторий на GitHub.
2. Загрузите в его корень оба файла: `index.html` и `wedding-music.mp3`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment**: Source — `Deploy from a branch`; Branch — `main`, папка `/ (root)`; нажмите **Save**.
5. Через ~1 минуту сайт откроется по адресу:
   `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`

## Приём ответов гостей (уже настроено)
Ответы формы уходят в вашу Google-таблицу через Apps Script (ссылка вписана в `CONFIG.sheetUrl` внутри `index.html`). Если понадобится сменить таблицу — замените этот адрес на `/exec`-ссылку нового скрипта.

## Настройки (по желанию)
В начале тега `<script>` внутри `index.html` есть блок `CONFIG`:
- `date` — дата свадьбы (влияет на отсчёт и календарь);
- `sheetUrl` — приём ответов в Google-таблицу;
- `music` — путь к музыке (сейчас `wedding-music.mp3`).
